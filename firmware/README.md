# Firmware Workspace

The PlatformIO firmware entry point currently lives in `../src/main.cpp`.

As AURA develops, reusable firmware modules are organized under the repository's `core/`, `hardware/`, `sensors/`, `network/`, `ai/`, and `applications/` directories. This folder is retained for firmware-level assets, build guidance, and future packaging without duplicating the active PlatformIO source tree.
